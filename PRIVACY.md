# Privacy

Box Keeper collects nothing and sends nothing about you anywhere.

- **No accounts, ads, analytics, crash reporting or tracking.**
- **On your box:** it reads what it needs to do its jobs (whether the box is asleep, its network connection, which
  HDMI port it's on, memory use, the remote's button presses while it forwards them to the TV). None of it leaves the
  box, except the button presses below.
- **Your TV:** while the TV is on another input, the remote's arrows, OK, Back and play keys are sent to your TV over
  your home network. It also asks the TV what it's showing.
- **GitHub:** only if "Update Box Keeper" or "Keep apps up to date" is on, it asks GitHub once a day for the newest
  release and downloads it. GitHub sees your network address, as with any download.
- **Accessibility:** the remote helper is an accessibility service because that's the only way an app can see the
  remote's buttons. It doesn't read the screen or anything you type.
